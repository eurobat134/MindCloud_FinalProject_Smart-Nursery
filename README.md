# Smart Nursery Guardian — PCB Design (Altium)

## Overview
4-layer PCB designed in Altium Designer for the Smart Nursery Guardian 
system. The board interfaces the STM32F401CEU6 microcontroller with all 
project sensors and actuators, and is manufactured-ready for JLCPCB.

## Layer Stackup
| Layer | Name         | Type   | Assigned Net     |
|-------|--------------|--------|------------------|
| L1    | Top Signal   | Signal | Component side   |
| L2    | GND Plane    | Plane  | GND              |
| L3    | Power Plane  | Plane  | +3V3 / +5V       |
| L4    | Bottom Signal| Signal | Routing          |

Board thickness: 1.6mm
Copper weight: 1oz outer, 0.5oz inner

---

## Design Rules
Follows JLCPCB 4-layer manufacturing capabilities:
- Minimum trace width:     0.127mm
- Minimum clearance:       0.127mm
- Minimum via hole:        0.3mm
- Minimum via outer dia:   0.6mm
- Board edge clearance:    0.3mm
- Solder mask expansion:   0.051mm

Design rules file: 4layer-1oz.RUL
Source: github.com/ayberkozgur/jlcpcb-design-rules-stackups

---

## Microcontroller
STM32F401CEU6 — UFQFPN-48, QFN 7x7mm, 0.5mm pitch
- VCAP_1 (pin 22): 2.2uF to GND — mandatory for stable operation
- VSS-EP (pin 49): connected to GND plane (thermal pad)
- Crystal: 8MHz HSE with 22pF load caps

## Schematic Sections
1. Power Supply     — USB Micro-B + screw terminal, AMS1117-3.3 LDO
2. Microcontroller  — STM32 core, crystal, NRST, Boot0, decoupling
3. Sensors          — DHT11, LDR, MQ-9 gas sensor, PIR
4. Actuators        — L293D motor driver, servo, buzzer
5. LED Indicators   — RGB LED (header), room LED (header)
6. Debug & Comms    — SWD 5-pin header, UART header

---

## Power Architecture
Input:  5V via USB Micro-B or 2-pin screw terminal (5V/2A minimum)
3.3V:   Generated by AMS1117-3.3 LDO (SOT-223)
5V rail feeds: Servo, L293D motor supply, PIR, gas sensor
3.3V rail feeds: STM32, L293D logic, DHT11, LDR divider

---

## Key Component Notes
- L293D: SOIC-16 — all 4 GND pins (4,5,12,13) connected to GND plane
- MQ-9 gas sensor: powered from 5V, AOUT scaled via 10k/20k
  voltage divider before connecting to STM32 ADC (3.3V safe)
- DHT11: single-wire protocol on PA0, requires 4.7k pull-up to 3.3V
- USB D+/D-: routed as differential pair on L1 (Top)
  Width: 0.2mm, Gap: 0.2mm, targeting 90Ω differential impedance

## How to Open
1. Open Altium Designer 26 or later
2. File > Open Project > select .PrjPcb
3. Open .SchDoc to review schematic
4. Open .PcbDoc for PCB layout
5. Design > Rules to review JLCPCB constraints
6. Run DRC to verify clean status before any modifications
